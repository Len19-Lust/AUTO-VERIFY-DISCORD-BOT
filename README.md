# Discord Verification Bot

Bot ini melakukan verifikasi aliansi pemain berdasarkan gambar profil dari game dan OCR (Tesseract).

## Fitur
- Slash command `/verify`
- OCR gambar dan deteksi nama aliansi
- Otomatis memberi role yang sesuai di Discord

## Deploy ke Railway
1. Fork repo ini
2. Masuk ke [Railway.app](https://railway.app)
3. Deploy from GitHub → pilih repo ini
4. Tambahkan Environment Variable: `TOKEN`
